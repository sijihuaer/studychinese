# 语文高效学习法

> **申怡 著**　北京联合出版公司　2022 年 1 月
> ISBN 978-7-5596-5130-3

一本把语文"拆开讲透"的书：从最小的**字**，一路讲到最大的**文**，把中学语文的九个环节串成一条可以一步步走的台阶。

---

## 这本书讲什么

很多孩子学语文的状态是：背了很多、刷了很多，分数却总是差一口气。问题往往不在努力程度，而在于没有掌握语文的**底层逻辑**——字为什么这么写，词为什么这么用，句子为什么这么组织，文章为什么这么走。

作者把语文学习拆成九个环节，环环相扣：

> 字不离词，词不离句，句不离段，段不离文。

全书按"字 → 词 → 句 → 段 → 景 → 境 → 层 → 思 → 文"的顺序展开，每一章都给可操作的方法，而不是让你去背答题模板。比如：

- **观字**：六种造字法，加上解字四法（知识迁移法、语境推断法、语法分析法、字形推断法）
- **解词**：解词三大法门——实词构筑形象、虚词表达态度、注重词语搭配
- **析句**：细分法 + 紧缩法，攻破古今句子的难关
- **组段**：用"逻辑的钩子"钩住语段的重难点
- **赏景 / 悟境**：四种情景关系、意象的四种类别，读透诗歌与散文
- **理层 / 辨思**：文脉（结构与线索）与意脉（情感与思想的轨迹）双层阅读
- **成文**：立意是魂魄、结构是骨架、材料是血肉；龙睛 → 凤头 → 猪肚 → 豹尾

序言里有一句话，把书名解释得很清楚：

> 掌握语文知识的源起，并能更好地、快速地运用，是为高效。
> 掌握语文知识的本质，能系统地、重复地获取，是为学习。

## 作者简介

**申怡**，语文教师、阅读推广人。曾在人大附中任教二十余年，带过多届高三毕业班，并多年担任北京高考语文阅卷作文组组长。2016 年离开人大附中，2020 年创立"申怡读书"，以"领读人"自居，长期带家长和孩子读《古文观止》《史记》等经典，倡导"群文阅读""大语文"的打通式学习。

她常讲的一句话是：**一切语文问题，本质上都是阅读问题。**
